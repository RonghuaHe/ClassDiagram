Privacy Policy

SourcePrism for macOS · Effective October 13, 2026

Summary

SourcePrism does not collect, store, or sell your personal data. There are no accounts, no analytics, no advertising, and no tracking. Your source code is read and analyzed locally on your Mac and is never sent to the developer.

Your files

SourcePrism only reads the folders and files you open. Diagrams, layouts, and settings are saved on your Mac. Git features run locally against the repositories you open.

Optional AI assistant

The terminal includes an optional AI assistant that is off until you enable it. It only works with an Anthropic API key that you provide. Before the first request, SourcePrism asks for your consent. After that, when you ask a question, the question and the terminal content shown in the request are sent directly from your Mac to Anthropic to generate an answer. They are not sent to the developer. Anthropic's handling of that data is governed by the Anthropic Privacy Policy. Your API key is stored in the macOS Keychain. You can withdraw consent or delete the key at any time in Settings.

Other network requests

  • Images in Markdown files. When you preview a Markdown file that references an image on the web, SourcePrism downloads that image from the address written in the file, like a web browser would.
  • Update checks (website edition only). The edition downloaded from GitHub checks ronghuahe.github.io for new versions. No personal information is included. The Mac App Store edition is updated by the App Store and does not make this request.

Licenses for the website edition are verified offline. No license information is sent anywhere.

Passwords

If you save Git account passwords in Settings, they are stored in the macOS Keychain on your Mac only.

Children

SourcePrism is a developer tool and is not directed at children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.

Contact

Questions about privacy: open an issue on GitHub.

隐私政策

SourcePrism（macOS）· 2026 年 10 月 13 日生效

概要

SourcePrism 不收集、不保存、不出售你的个人数据。没有账号、没有统计分析、没有广告、没有追踪。 源代码只在你的 Mac 上读取和分析，不会发送给开发者。

你的文件

SourcePrism 只读取你打开的文件夹和文件。图表、排版和设置都保存在你的 Mac 上。Git 功能只在本机对你打开的仓库操作。

可选的 AI 助手

终端里的 AI 助手默认关闭，需要你提供自己的 Anthropic API Key 才能使用。第一次发问前，App 会先征得你的同意。 之后每次发问，问题和请求里附带的终端内容会从你的 Mac 直接发送给 Anthropic 用于生成回答，不会发送给开发者。 Anthropic 如何处理这些数据，以 Anthropic 隐私政策为准。 API Key 保存在 macOS 钥匙串中。你可以随时在设置里撤回同意或删除 Key。

其他网络请求

  • Markdown 里的图片：预览引用了网络图片的 Markdown 文件时，App 会像浏览器一样，从文件里写的地址下载图片。
  • 检查更新（仅官网版）：从 GitHub 下载的版本会访问 ronghuahe.github.io 检查新版本，不包含任何个人信息。 Mac App Store 版由 App Store 负责更新，不发这个请求。

官网版的许可证在本机离线验证，不会发送到任何地方。

密码

在设置里保存的 Git 账户密码只存放在你 Mac 的钥匙串中。

儿童

SourcePrism 是开发者工具，不面向儿童。

变更

本政策如有变更，会在本页面发布新版本并更新生效日期。

联系方式

隐私相关问题：在 GitHub 提交 Issue。
